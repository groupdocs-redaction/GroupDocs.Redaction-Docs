GroupDocs provides free technical support for all users, including evaluation. Post questions on the [Free Support Forum](https://forum.groupdocs.com/c/redaction/33). Paid customers can also use the [Helpdesk](https://helpdesk.groupdocs.com/).

When reporting an issue, include product version (`@groupdocs/groupdocs.redaction`), Node.js and Java versions, a short code sample, and (if possible) a sanitized document that reproduces the problem.
