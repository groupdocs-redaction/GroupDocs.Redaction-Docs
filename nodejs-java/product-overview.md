GroupDocs.Redaction for Node.js via Java is a Node.js wrapper around [GroupDocs.Redaction for Java](https://docs.groupdocs.com/redaction/java/). It exposes the same redaction capabilities — text, metadata, annotations, image areas, page removal, policies, and rasterized PDF output — to JavaScript applications.

The package runs on Windows, Linux, and macOS with a local Java runtime. No Microsoft Office or Adobe Acrobat is required.

## Main capabilities

* Exact phrase and regular-expression text redaction (replacement string or colored box)
* Metadata erase and search/replace
* Annotation rewrite or deletion
* Image-area redaction
* Page/slide/worksheet removal
* Save in original format or as a rasterized PDF
* OOXML compliance options for Word saves
* Explicit file type via `LoadOptions` when opening streams

For a full feature list see [Features overview]({{< ref "redaction/nodejs-java/getting-started/features-overview.md" >}}).
