1. Install the package: `npm install @groupdocs/groupdocs.redaction`.
2. Ensure `JAVA_HOME` points to a JDK/JRE 8+.
3. Place sample documents next to your script (or update paths).
4. Optionally call `License.setLicense(...)` to remove trial limits.
5. Run with `node your-script.js`.

Java examples in the [GroupDocs.Redaction for Java](https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-Java) repository map 1:1 to the Node.js API surface; only the language and packaging differ.
