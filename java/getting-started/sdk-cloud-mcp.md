Use this page to pick a line. They are not interchangeable, and this Java documentation describes only the on-premise SDK.

## GroupDocs.Redaction for Java (this documentation)

Choose the on-premise Java SDK when your application calls the library on the JVM.

- Package: `com.groupdocs:groupdocs-redaction`
- Repository: https://releases.groupdocs.com/java/repo/
- Install: [Installation]({{< ref "redaction/java/getting-started/installation.md" >}})
- Examples: https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-Java
- API reference: https://reference.groupdocs.com/redaction/java/

## GroupDocs.Redaction Cloud

Choose Cloud when you want the hosted REST line instead of the on-premise JAR. Cloud is a separate product. This repository does not document Cloud APIs.

- Java Cloud: https://products.groupdocs.cloud/redaction/java

## MCP

Choose MCP when an AI client should call redaction tools. The MCP server is not the Java SDK. Do not copy MCP tool schemas into Java application code.

- Server repository: https://github.com/groupdocs-redaction/GroupDocs.Redaction.Mcp
- MCP docs: https://docs.groupdocs.com/redaction/mcp/

## Online app

The browser app is neither the SDK nor Cloud:

https://products.groupdocs.app/redaction/total
